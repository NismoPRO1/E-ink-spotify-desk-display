#  Spotify E ink Desk Display 
<img width="1054" height="606" alt="image" src="https://github.com/user-attachments/assets/e7c0ebe0-b6e0-4396-9548-76019c682b16" />

This is a Spotify E-Paper Display uses a Raspberry Pi Zero 2 W to fetch and show current track information on a compact, since it is e-ink it consumes low power. It is build inside a 3d printed case.  




# Why build it?

well for starters it is a amazing project for beginners and secondly it makes for a amazing small desk project


currently it is required for it to be plugged in to work, however i will also soon release a version which can work on AA batteries.

you can either build this with a black and white E-ink display or a color E-ink display.
Check BOM.csv For all parts and their links.


for the 3d printed parts i could use PETG.

# Wiring and connections explained for beginners 

<img width="2482" height="1040" alt="image" src="https://github.com/user-attachments/assets/fb03c609-faa2-438e-acd3-8d4c714c4817" />

The 5V adapter will be connected to the Raspberry Pi Zero 2, which will act as our main power supply.
The sd card will be inserted into the raspberry Pi.

the display needs power and the pi can provide 3.3Vs, along with the GND(ground) and the SPI signals which will all be connected to the adapter board. 
and from the adapter board using the FPC cable you will connect to the screen.

and that is basically everything explained.
